## About Me 👋
Hi, I'm Jewook Yoo from Seoul, South Korea — you can call me Mason 👋  
I'm a frontend-focused software engineer working on developer-facing web platforms.

Currently, I work at Kakao Corp on [Kakao Developers](https://developers.kakao.com/changeLang?lang=en), a web platform that helps external developers configure, test, and integrate Kakao APIs.

I enjoy building and maintaining complex frontend systems where data fetching, form handling, error states, and user workflows need to be reliable and predictable. I primarily work with React and Next.js, and I care a lot about long-term maintainability and developer experience.

I'm interested in contributing to open-source projects, especially those related to frontend infrastructure, developer tooling, or data-heavy web interfaces.
